# `tables/`

Summary and comparison tables for experiment results.

## Purpose

Store final comparison tables, performance summaries, and ablation studies in tabular format.

## Format

- CSV for spreadsheet compatibility
- JSON for programmatic access
- Include headers and clear column names

## Examples

- `comparison_models.csv` – Model performance comparison
- `ablation_study.json` – Ablation study results
- `hyperparameter_sweep.csv` – Grid search results
