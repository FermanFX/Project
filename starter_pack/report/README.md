#This directory contains the reports for the **Math4AI Capstone Project**.

## 📁 Structure
- **final report** → Main results, methodology, and key conclusions  
- **additional report** → Extended analysis, detailed derivations, and deeper experiments  

## 📌 Notes
- Reports are provided primarily in **PDF format**  
- Corresponding **LaTeX source files** are also included  
- All results are based on **reproducible experiments**

## 🎯 Focus
The project investigates when a **one-hidden-layer neural network** outperforms a **linear classifier**, and when additional complexity is unnecessary.
